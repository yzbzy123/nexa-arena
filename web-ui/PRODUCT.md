# Nexa Arena

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React, TypeScript, Tailwind CSS and shadcn/ui (Radix), hosted in a Windows WebView2/C# desktop application. Fontsource provides fonts.

## Users

CS2 and VALORANT players on Windows, including laptops with external monitors and stretched fullscreen resolutions.

## Product Purpose

A free local game toolbox for display recovery, crosshair codes, sensitivity, audio, optional Windows settings and diagnostics.

## Capabilities and Constraints

The C# backend executes display recovery, configuration repair, monitor and icon operations, audio and hotkeys. The toolkit includes 42 native settings, local selection profiles, memory controls, startup/task/service/network managers, documented NVIDIA settings, experimental device parameters, current-user application deployment, explicit game-process monitoring and fixed system repair jobs. Protected or unsupported objects remain readonly. Package removal and file repair are not ordinary reversible settings. Native changes require explicit controls and confirmation; preview mode does not change the system. Detailed limits are in FEATURES.md at the repository root.

## Brand Commitments

Nexa Arena; free game toolbox; author 2ndWind; QQ group 1105050795. Chinese-first light precision interface, consistent across pages.

## Quality Evidence

Regression tests, native readonly queries, safe desktop previews and documented API contracts verify implementation boundaries. Preview and copied crosshair code use the same decoded data. Game rendering and performance remain hardware-dependent.

## Product Principles

Make actions, scope and recovery easy to find. Save original values before mutation, verify afterward and preserve outside changes. Keep diagnostics separate from performance claims.
