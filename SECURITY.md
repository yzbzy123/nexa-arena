# Security

Nexa Arena can change Windows display, audio, process and system settings. Only apply options whose effects you understand. Back up important data before application removal, system repair or experimental device tuning.

- Experimental MSI and interrupt-affinity settings may require a restart and can cause device problems.
- Application removal and Windows file repair are not ordinary reversible setting changes.
- Protected system, security and anti-cheat components are not disabled automatically.
- The project does not inject code into games or bypass anti-cheat restrictions.

For security reports, contact 2ndWind at QQ 2583053476. Do not post credentials, personal configuration files or private device logs in public issues.
